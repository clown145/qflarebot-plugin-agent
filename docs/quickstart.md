# 快速开始

## 前置条件

| 项 | 要求 |
| --- | --- |
| QFlareBot 版本 | `apiVersion: 2`（用到 `ctx.db.batch()`） |
| 依赖插件 | **`qflarebot-plugin-llm` 必需** —— 本插件不含模型接入 |
| 数据库 | D1（必需）、KV（必需） |
| 可选绑定 | R2（虚拟工作区、大文件）、Images / Browser Run（本插件暂未用） |
| 平台权限 | QQ 群：需要「接收全部消息」才能拿到群内非 @ 消息；不需要也行，@ 就能用 |

## 安装

1. **先装 LLM 插件**。没装的话面板会直接拦下安装并提示先装提供者
   （`depends: { llm: '*' }` 是硬依赖）。
2. 装本插件。
3. 打开**面板 → 插件页面 → Agent**。
4. 在「模型」里选一个别名（来自 LLM 插件的模型列表），然后「测试」一下。

装完之后如果 LLM 插件被停用或卸载，Agent 会回复「需要的 LLM 接口插件没有启用」，
而不是抛内部错误。

## 第一次对话

| 场景 | 怎么触发 |
| --- | --- |
| 群里 | `@机器人 你好` 或 `/你好`（`/` 是默认唤醒前缀） |
| 单聊 | 直接说话（默认不需要前缀） |
| 显式提问 | `/agent 你好`（走命令路径，等价于聊天） |

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `/agent <问题>` | 问一句（和直接聊天等价） |
| `/agent reset` | 清空本会话记忆（打断正在跑的、清队列、删历史） |
| `/agent schedule` | 看本会话的定时任务；`/agent schedule cancel <id>` 取消 |
| `/agent persona [名字]` | 查看或切换本会话人格 |
| `/agent status` | 看模型别名、可用模型、开关、限额 |

> **注意**：这 5 个命令目前**都没有权限门槛**，群里任何成员都能执行，
> 包括 `/agent reset`（能清空整个群的记忆）。如果是公开群，建议关注这一点。

## 首次配置清单

按顺序勾一遍，基本就能正常工作：

- [ ] 「模型」选好别名，点测试确认能通
- [ ] 「系统提示词」或者「人格」设成你想要的语气
- [ ] 「限额」按需要调步数 / 工具调用数（默认 8 / 12）
- [ ] 想让它能联网查资料 → 在面板配置表单填 `search_api_key`（Tavily）
- [ ] 想用工作区（读写文件）→ 确认机器人绑了 R2，再打开 `enable_vfs`
- [ ] 想用定时提醒 → 打开 `enable_schedule`（cron 每分钟跑一次）
- [ ] 公开群建议设 `rate_limit_per_minute` 和 `content_filter_keywords`
